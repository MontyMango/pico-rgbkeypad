# Installing the `.uf2` file on the Raspberry Pi Pico

To install the `adafruit-circuitpython-raspberry_pi_pico-en_US-9.0.5.uf2` file on a Raspberry Pi Pico (2040):

1. Unplug the Pico.
2. Hold the `BOOTSEL` button while connecting it to your computer via USB.
3. Release the button when a drive named RPI-RP2 appears on your computer.
4. Drag the `adafruit-circuitpython-raspberry_pi_pico-en_US-9.0.5.uf2` file onto the RPI-RP2 drive.
5. The Pico will automatically reboot and install the firmware onto itself.

<br>

Once the Pico has rebooted, you will see a drive named `CIRCUITPY` pop up. Congrats! You have succesfully installed CircuitPython onto your Pico!
